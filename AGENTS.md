# Project Rules & Guidelines

## 🚨 Git & Deployment Rules (STRICT)

1. **ASLA OTOMATİK PUSH YAPMA:**
   - Kullanıcı açıkça "pushla", "git push yap", "maine pushla" veya benzeri bir talimat vermediği sürece **KESİNLİKLE `git push` ÇALIŞTIRMA**.
   - Değişiklikleri yerel dosyalar üzerinde yap, gerekirse yerel test/build komutlarını çalıştır ve yerel commit al. Ancak uzak sunucuya (`origin main`) gönderme işlemi yalnızca kullanıcının açık onay ve emriyle yapılacak.
